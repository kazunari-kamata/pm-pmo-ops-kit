# BIダッシュボード操作ガイド

## 起動前の準備

分析データベースがない場合は、リポジトリルートで次を実行します。

```sh
python -m bi.etl.run
python -m streamlit run bi/app/dashboard.py
```

画面のサイドバーでプロジェクトと対象期間を選びます。終了日は進捗KPIの基準日になります。期間を狭めると、予算・工数・リスク・課題の表示対象も絞り込まれます。

## 画面一覧

| 画面 | 主な内容 | 主な確認行動 |
| --- | --- | --- |
| エグゼクティブサマリー | 全体予算、進捗、節目、高リスク、注意対象 | 支援・エスカレーションの優先順位を決める |
| 進捗分析 | WBSの計画対実績、期限超過、節目 | 遅延作業の担当・依存関係・回復策を確認する |
| 予算・工数分析 | 予算対実績・見込、月次、役割別工数、適用単価、人件費 | 工数差異・単価差異・超過要因と承認済み変更を確認する |
| リスク・課題分析 | 重要度・状態・未解決期間・案件比較 | 高重要度の未解決項目を優先して対応する |

## KPI定義の確認とCSV出力

各画面の「KPIの定義・判定基準を確認」を開くと、目的、計算式、NULL・ゼロの扱い、判定の考え方を確認できます。表の「CSVを出力」から、現在の絞り込み条件に対応したデータを出力できます。グラフは同じ表の集計結果を使うため、図表間で条件がずれません。

## データがない場合

選択条件に該当するデータがない場合は、空白のグラフではなく案内メッセージを表示します。分析データベース自体がない場合はETLの実行を案内します。入力エラーを画面上で補正せず、CSVを修正してETLを再実行してください。
